# Global Olympic Sports Performance Analysis

Interactive Tableau dashboard analysing Olympic sports performance (1992-2026).

## Contents
- Olympic_Dashboard.twbx : Tableau workbook (9 visualisations, 3 scenarios)
- athletes.csv, medal_results.csv : Datasets
- Screenshots : Dashboard and visuals
- Documentation : Empathy map, problem statements, journey map
